HelpMission="In naher Zukunft ist es Ihre Aufgabe, in Städte auf der ganzen Welt zu fahren und medizinische Versorgung zu liefern. In dieser Zukunft ist die Währung für alles elektrische Energie, Sie werden für jede Lieferung mit einem Power-Up in Kilojoule (kJ ).

Sie können durch die Stadt laufen oder laufen oder einen Wagen oder einen Bus nehmen. Ein Bus ist billig zu fahren, aber man muss dorthin gehen, wo er hingeht. Ein privater Wagen kostet mehr, aber Sie können seine Route steuern.

Wählen Sie zu Beginn eine der vier Städte auf der ersten Ebene aus. Sobald die Karte geladen ist, sehen Sie ein Viertel der von Ihnen gewählten Stadt.

Wählen Sie als Nächstes einen Lieferort in dieser Nachbarschaft aus. Ihnen werden drei Standorte angeboten: eine kurze Distanz, eine mittlere und eine längere. Die Zahlung, die Sie für die Lieferung erhalten, steigt mit der Entfernung. Sobald Sie den Drop-off erreichen, werden Ihnen weitere drei Standorte angeboten.

Mit guter Planung erreichen Sie einen besonderen Ort, an dem Sie eine kleine Flasche, ein blaues Fläschchen, abholen können. Seine Standorte werden auf der Karte angezeigt. Jedes Fläschchen enthält eine Komponente für ein neues Medikament, das die Welt vor der nächsten Krankheitsbedrohung schützen wird.

Wenn du anfängst, hast du Zugang zu einer Ebene, und wenn du mehr Energie gewinnst, werden sich weitere Ebenen öffnen. Es gibt acht Ebenen und vier Städte auf jeder Ebene. Ab Level drei kannst du auch deine eigene benutzerdefinierte Nachbarschaft an einem Ort deiner Wahl bauen. Jede benutzerdefinierte Nachbarschaft enthält außerdem ein Fläschchen.

Ihre Mission ist es, 36 Fläschchen zu finden und die Menschheit zu retten.

Tipps:
- Achten Sie bei Ihrer Bewegung in der Stadt auf Menschen, die viruspositiv sind: Seien Sie in Menschenmengen und in Bussen besonders vorsichtig
- Wenn Ihnen die angebotenen Abgabestellen nicht gefallen, können Sie einen weiteren Satz von drei bezahlen. Der Preis wird unter den Optionen angezeigt
- Wenn Sie nicht an der Ampel warten möchten, können Sie die rote Ampel überspringen, aber wenn eine Kamera vorhanden ist, zahlen Sie eine Geldstrafe oder Schlimmeres
- Sie können [Voranbringen] verwenden, um eine Route im Voraus zu wählen: Die Route kann direkt zu Ihrem Drop-off führen oder über Bonusbatterien, um zusätzliche kJ zu erhalten
- Sie können nur an einer ausgewiesenen Wagen-Zone in einen Wagen einsteigen: Diese werden mit einem Wagen-Symbol auf der Fahrbahn angezeigt
- Sie können nur an einer Bushaltestelle in einen Bus einsteigen: Einige Bushaltestellen werden von mehr als einer Buslinie genutzt
- Wenn Sie sich in einem Wagen befinden, können Sie die [Wagen-Route] Taste verwenden, um die Zielzone des Wagens zu ändern, in der Sie aussteigen
- Wenn Sie an einer Bushaltestelle warten, können Sie bei mehreren Buslinien wählen, welche Route Sie nehmen möchten
- Wenn Sie in einem Bus sitzen, können Sie die Haltestelle auswählen, an der Sie aussteigen möchten
- Wenn Sie in einem Wagen oder Bus sitzen, können Sie die Abandon-Taste drücken, um auszusteigen, wenn er angehalten wird, aber Sie zahlen eine Geldstrafe."
